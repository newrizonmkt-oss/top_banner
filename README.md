# top_banner

📁 파일 설명 및 파일의 역할
information.jpg : 모든 상품 페이지에 표시되는 배너 이미지
go.html : 배너 클릭 시 이동할 링크를 관리하는 파일

🖼️ 배너 이미지 교체하는 법

1. 새 이미지 파일 이름을 반드시 information.jpg로 변경
2. 이 레포지토리에서 Add file → Upload files 클릭
3. 새 파일 드래그해서 올리기
4. 하단 Commit changes 클릭
5. 1~2분 후 홈페이지에 자동 반영 ✅


⚠️ 파일 이름이 다르면 반영 안 됨. 반드시 information.jpg 그대로!


🔗 클릭 링크 변경하는 법

1. 이 레포지토리에서 go.html 클릭
2. 우측 상단 연필 아이콘(✏️) 클릭
3. 아래 부분에서 URL만 교체:

url=https://여기를바꾸면됩니다

우측 상단 Commit changes 클릭 → 바로 반영 ✅


⚡ 이미지가 안 바뀌어 보일 때
브라우저가 이전 이미지를 기억하고 있는 경우입니다.

Ctrl + Shift + R (윈도우) 또는 Cmd + Shift + R (맥) 으로 강력 새로고침
